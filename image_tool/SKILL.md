# 云盘图像处理工具

意图分发入口。命中后读取对应子能力 `index.md`，按其规则执行；本文件不重复参数与脚本细节。写操作须确认；图片 `fileId` 须来自 CLI。

## 意图分发

| 用户意图 | 子能力 | 规则 |
|----------|--------|------|
| 文生图、图生图、改图、扩图、美颜、抠图、漫画风、画质/老照片修复、宝宝长相、头像、搜索/整理后继续改图 | AI生图 | `./ai_image_generate/index.md` |
| 裁剪、旋转、翻转、改比例后存云盘（不经 AI） | 图片编辑保存 | `./image_edit_save/index.md` |
| HEIC/LIVP 转 JPG（格式转换，本地文件） | 图片编辑保存 | `./image_edit_save/index.md` |

图片配文按 AI生图 `index.md`「能力边界」处理。未读子文档不得执行。

## 能力边界

本工具集覆盖 **AI 生图**（文生图 + 图生图，统一入口为 AI生图）能力。当用户请求**超出此范围**时，按以下流程处理，不得臆造或强行套用：

1. **如实告知**：明确说明该需求不在当前工具集能力范围内。
2. **列举相似能力**：找出与用户需求最接近的能力，作为备选推荐，并简述其能做什么。
3. **询问是否切换**：向用户确认是否切换到推荐的能力；得到明确确认后，再读取对应子能力 `index.md` 执行。未确认前不得擅自执行。

## 执行流程

1. **判定分支**  
   命中上表某一行 → 读取该行 `index.md`，以其为唯一执行规则。  
   「生成/画/做一张图」等泛生图、未点名具体工具 → 一律 `./ai_image_generate/index.md`。有输入图（用户上传、改图/合成、承接前序搜索或整理结果）按图生图；无图按文生图。  
   无匹配 → 走「能力边界」，不得擅自执行。
2. **按子文档执行**  
   参数、确认、上传与回执全部以子文档为准。本文件不写请求体或脚本内部字段。
3. **越界**  
   如实告知不支持 → 推荐上表或转交技能 → 用户确认后再读对应文档。
