# 文件 / 图片搜索

四场景意图分发入口。

## 场景路由

四个搜索场景，按**搜索词（语义/关键词）× 搜索条件 × 搜索目标**三维度区分。一个请求跨多场景时逐个执行，不合并命令。

### 自然语言找图

用一句话描述要找的图——画面内容、地点、时间、事件、人物等任意维度都写进这句自然语言里。

- **搜索词**：一句自然语言整句
- **搜索目标**：仅图片
- **例子**：找我旅游的照片

#### 执行命令

```bash
python3 {baseDir}/scripts/main.py semantic-search --query "<查询语句>"
```

| 参数 | 必填 | 默认 | 说明 |
|------|------|------|------|
| `--query` | 是 | — | 自然语言整句，如「海边日落时小孩奔跑的照片」；按文件名搜索请改用 `search --keyword`（文件搜索场景） |

#### `--query` 传入要求

**规则**：把用户原话整理成**一句**通顺的中文检索语句，尽量贴近用户原本措辞。语义检索理解句内的时间/地点/人物等约束；召回按传入 query 匹配——**约束被删或被改写的部分在召回中失效**（丢时间→其他时段混入；丢「我」→「我和儿子」类合影漏召）。

- **删**：语气词、口头禅、寒暄、请求表达（帮我/麻烦/给我看看）、搜索动作词（找/找找/搜/看看，动作词后的检索对象与「我」保留）、无意义重复（「找一找一下」→「找」）；用户边说边改主意时只保留最终意图（「找猫的，啊不对，是狗」→ 只留狗）。
- **纠**：仅纠正明显的同音/形近/语音转写错误（照骗→照片、美瑰→玫瑰、杭洲→杭州）；人名、地名、品牌等专有名词不改。
- **留（实质约束一个不能丢）**：时间、地点、人物关系（我/亲属称谓/人名，及合影/同框/一起做某事）、活动/动作、对象、场景、视觉属性（颜色/数量）、表情情绪及其连接词（笑得/哭得/看起来）、结果数量与分组（只要一张/看两张就够了）。
- **禁**：扩写、联想、补近义词、同义替换——「我妈」不改「母亲」、sunset 不改「日落」；实体与关系词以用户原话为准，转述中的同义改写不得照抄。
- 已是干净的检索语句 → 原样传入。

**时间约束留在句内**：时间词（这个月/去年/上周）原样写进 `--query` 即可；**禁止因带时间词改投 `search --keyword` + 时间过滤**——关键词只匹配文件名，画面描述类请求必然漏召。

正例：

- 「帮我找我和儿子的合照」→ `--query "我和儿子的合照"`（剥请求前缀，其余原样）
- 「呃帮我找一找我去旅游的照片，就是去年在北京的，跟我儿子一起」→ `--query "去年我和我儿子在北京旅游的照片"`（碎片合并成一句，时间/称谓/关系全保留）
- 「搜这个月拍的海边的图片」→ `--query "这个月拍的海边的图片"`（时间词留在句内，不改投 `search --keyword` 时间过滤）
- 「找我妈去北京旅游的照片」→ `--query "我妈去北京旅游的照片"`（称谓「我妈」、地名「北京」原样保留）

反例：

- 「我和儿子的合照」→ `--query "和儿子的合照"`：丢主语「我」，搜不到「我和儿子」类结果
- 「找我妈的照片」→ `--query "找母亲的照片"`：称谓改写，原话语境失配漏召
- 「我在北京拍的 sunset」→ `--query "我在北京拍的日落"`：内容词翻译改写，偏题
- 「这个月拍的海边的图片」→ `search --keyword "海边" --start-at … --time-field takenAt`：找图请求因带时间词降档为文件名关键词检索，画面命中的图全部漏召


### 个人云文件和个人云文件夹搜索

- **搜索词**：根据文件关键词和结构化过滤任意组合搜索，可不限文件关键字。
- **搜索条件**： 
  1. 时间条件：拍摄时间、创建时间、更新时间
  2. 指定文件后缀搜索
  3. 指定文件大小搜索
- **搜索目标**：多种类型（综合搜索），指定类型（图片、音频、视频、文档、其他类型文件、文件夹）
- **范围**：任意目录（`--scope-in`/`--scope-out`）或备份口径目录（`--backup-folder`）
- **例子**：搜xx文件夹、搜云盘上的文档、搜云盘的全部图片、搜名字含"刘德华"的图片、搜备份里的合同、在手机备份里找图片、在微信备份里找文档

#### 执行命令

```bash
python3 {baseDir}/scripts/main.py search [--keyword "毕业"] [--type image,doc] [--ext jpg,png] \
    [--start-at "2026-01-01 00:00:00"] [--end-at "2026-08-01 00:00:00"] \
    [--size-min 10MB] [--size-max 2G] [--scope-in <parent-fileId1>,<parent-fileId2>] [--scope-out <parent-fileId3>,<parent-fileId4>] \
    [--backup-folder 手机备份]
```

| 参数 | 默认 | 说明                                                                                        |
|------|------|-------------------------------------------------------------------------------------------|
| `--keyword` | 无 | 文件名/标题关键字；省略即纯条件筛选；可与全部过滤参数组合                                                             |
| `--type` | 综合（不传） | 类型 CSV **词形**：`image`/`audio`/`video`/`doc`/`folder`/`other` 可多选，如 `image,doc`；不传=综合      |
| `--ext` | 无 | 扩展名 CSV（如`jpg,png`，前导 `.` 可省）                                                             |
| `--start-at` / `--end-at` | `--end-at` 缺省=当前时间 | 时间窗起止，`--end-at` 可省略（=搜到当前时刻）                                                             |
| `--time-field` | 随 `--type`：纯图片=`takenAt`，其余=`updatedAt` | `createdAt`（创建时间） / `updatedAt`（更新时间） / `takenAt`（拍摄时间，仅 `--type image` 纯图片可用）；只在传时间范围时生效 |
| `--size-min` / `--size-max` | 无 | 大小区间，支持 `10MB` / `2G` 等单位；与 `--type folder`（目录）互斥                                         |
| `--scope-in` / `--scope-out` | 无 | 目录范围内/范围外的**文件夹** fileId 列表（传文件 id 会整体报错，回执 `next.search-by-ids` 指路先生成 handle）；两参数互斥，各最多 20 个；与 `--backup-folder` 互斥 |
| `--recursive` | 不传（仅一层） | `true` = 递归检索所选目录的全部子目录；不传 = 只检索目录一层 |
| `--backup-folder` | 无 | 限定备份口径目录（见下方白名单）；可重复传多个口径；与 `--scope-in`/`--scope-out` 互斥 |

#### 备份口径目录

`--backup-folder` 只接受以下中文名（白名单校验，禁止传数字编码或自造目录名）：

| `--backup-folder` | 口径目录 |
|-------------------|----------|
| `手机备份` | 手机备份 |
| `手机图片` | 手机图片 |
| `手机音乐` | 手机音乐 |
| `手机视频` | 手机视频 |
| `同步盘` | 同步盘 |
| `139 邮箱` | 139 邮箱 |
| `来自电脑备份` | 来自电脑备份 |
| `来自微信备份文件夹` | 来自微信备份文件夹 |

不传 `--backup-folder` = 不限定备份口径（搜全盘）。

### 个人云文件上传、查看动态搜索

- **搜索词**：根据关键词搜索文件名，可不限关键字，重点是根据文件的上传、查看时间进行筛选。
- **搜索条件**： 文件上传时间、文件查看时间
- **搜索目标**：图片、音频、视频、文档、其他文件
- **例子**：最近在看/最近在听/最近上传/最近查看

#### 执行命令

```bash
python3 {baseDir}/scripts/main.py dynamic --start-at "2026-08-01 00:00:00" [--end-at "2026-08-23 00:00:00"] \
    [--type image|audio|video|doc] [--keyword "关键词"] [--kind view|upload]
```

| 参数 | 必填 | 默认 | 说明 |
|------|------|------|------|
| `--start-at` / `--end-at` | `--start-at` 是 | `--end-at` 缺省=当前时间 | 时间窗起止，`--end-at` 可省略（=搜到当前时刻） |
| `--keyword` | 否 | 空 | 不限关键字 |
| `--kind` | 否 | `view` | `view`=查看过的动态；`upload`=我上传的动态 |
| `--type` | 否 | 不传 | 动态类型：`image`=图片动态 / `audio`=音频动态 / `video`=视频动态 / `doc`=文档动态 / **不传=全部文件动态**；`folder`/`other`/多选报错 |

#### `--type` 路由

- 不传 `--type`：全部文件动态
- `--type image`：图片动态
- `--type audio`：音频动态
- `--type video`：视频动态
- `--type doc`：文档动态
- `--type folder` / `other` / 多选：报错「--type 仅支持 image/audio/video/doc（或不传=全部文件动态）」

### 批量 `<fileId>` 搜索文件详情

已知一批**文件**的 `<fileId>`，获取含 AI 分析信息的完整详情并产语料。

#### 执行命令

```bash
python3 {baseDir}/scripts/main.py search-by-ids --file-ids <fileId1>,<fileId2>,...
```

| 参数 | 必填 | 说明 |
|------|------|------|
| `--file-ids` | 是 | **文件** fileId CSV（英文逗号分隔），单次上限 20 |

- 只接受**文件** fileId：传入文件夹 `fileId` 会整体报错，回执 `next.search`
  给出改用 `search --scope-in <fileId> --recursive true --mode full` 的完整
  命令（先落盘 search.jsonl，支持断点续传），之后可用 refine、merge 等
  继续后续处理
- 用户点名文件夹时**禁止丢弃**：文件夹内容一律用 `search --scope-in` 承接；
  文件夹结果与文件结果需要合并时，用
  `refine --kind merge --from op_<6位编码1>/search.jsonl,op_<6位编码2>/search.jsonl`

## 场景特有约束

1. 用户只提到最近，那么默认是「最近一周」
2. **时间窗必须绝对值**：用户直接说「最近一周」时，Agent 先换算成具体起止时间再传参。
3. 用户没给时间范围 → 先澄清起止时间，不要默认全量（动态量大，全量搜索耗时）。

## 下游交接

当搜索结果非空时，返回 `<handle>`（`op_<6位编码>/search.jsonl`），记下 handle 交给下游命令；使用搜索结果的下游能力路由：
- 精选、去重、合并多份搜索结果。见 [REFINE.md](REFINE.md)
- 搜索结果按类别整理到个人云文件夹/相册/回忆故事。见 [ORGANIZE.md](ORGANIZE.md)

## 易混点

- **语义 vs 关键词**：一句自然语言 → 语义找图；关键字或纯条件 → 动态/文件搜索；「名为X / 名字叫X / 文件名含X」→ `--keyword`（文件搜索）。
- **「时间」三义**：语义找图把时间写进整句（语义检索理解句内时间，带时间词的找图**不因此改投文件搜索**）；动态搜索的时间窗 = 你查看/上传内容的时间；文件搜索的时间 = 文件本身的创建/更新/拍摄时间。
- **动态 vs 文件**：动态搜索搜的是「浏览/上传行为记录」，对象随时间窗流动；文件搜索搜的是「云盘静态文件」，对象稳定存放在云盘。
- **备份 vs 任意目录**：用户说「搜备份 / 在备份里找」→ `search --backup-folder`（备份口径目录白名单内）；用户给的是任意目录 id → `search --scope-in`。两者互斥。
