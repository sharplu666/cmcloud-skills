# 转存搜索（search-transfer）

按**转存来源**查云盘里转存来的文件：分享转存 / 圈子转存 / 发现转存。

## 什么时候用 / 不用

- **用**：用户问「分享转存的」「从圈子/群组/共享群/家庭云转存的」「发现转存来的」文件——来源词是路由锚点。
- **不用**：看/上传过的内容 → 个人动态搜索（[SEARCH-FILE.md](./SEARCH-FILE.md)）；按文件名/类型/时间搜全部文件 → 文件搜索（[SEARCH-FILE.md](./SEARCH-FILE.md)）。
- **转存类型一次只查一种**。用户只说「转存」没说来源时，**先问用户是哪种来源**（分享转存 / 圈子转存 / 发现转存），不要替用户选、也不要自行跑三遍。

## 来源口语映射（--transfer-type）

| 用户说法 | --transfer-type |
|---|---|
| 「分享转存」「从分享转存的」 | `5` |
| 「圈子转存」「从圈子/群组/共享群/家庭云转存的」 | `6`（群组/圈子/共享群/家庭云为同一协作空间） |
| 「发现转存」「从发现转存的」 | `7` |

## 时间与关键词（提示层换算，CLI 只收绝对值）

- `--start-at` 必填、绝对时间（支持 `2026-08-01`、`20260801`、`2026-08-01 10:30:00` 等写法）。「最近」= 当前日期往前倒推 7 天，由你换算后传入。
- `--end-at` 缺省 = 当前时刻；用户明确说了截止（如「到 8 月底」「昨天」）才传。只写日期（`2026-08-05`）即**含当天全天**（自动补 23:59:59）；要精确到零点请写完整时刻 `2026-08-05 00:00:00`。
- `--keyword` 只匹配**文件名**文本；「视频/照片/音乐」等类型词**不是 keyword**，不传即可（转存查询不支持按文件类型过滤）。无关键词不传。

## 执行命令

```bash
python3 {baseDir}/scripts/main.py search-transfer \
  --start-at "<开始时间>" \
  --transfer-type <5|6|7> \
  [--end-at "<结束时间>"] [--keyword "<文件名关键字>"] \
  [--page-size 10] [--page-after '<游标>']
```

## 翻页（手动游标）

- 回执 `next.next-page` 给出**完整翻页命令**：直接执行即可（全部参数已固化，仅追加了 `--page-after`）。
- 翻页时**所有参数必须保持一致**（时间窗/关键词/类型/页大小），只换游标，否则翻页失败。
- 无 `next.next-page` = 没有下一页。

## 结果转述口径

- 数字（共 N 条 / 本页 M 条）取自回执，勿编造；卡片已展示给用户，勿复述卡片内容。
- **结果非时间排序**：总结时禁止使用「最新」「最近一条」等时间排序措辞。
- 空结果：回执 sayToUser 已带建议（调整时间范围），如实转述、可建议扩大时间窗，**禁止自动改参数重查**，是否重查由用户决定。
- 转存查询是**终端查询**：不产生 `<handle>`，不能接精选/去重/整理下游。

## 完整例子

用户：「看看我这些年从分享转存过来了什么」

```bash
python3 {baseDir}/scripts/main.py search-transfer \
  --start-at "2023-01-01" \
  --transfer-type 5
```

用户：「上个月从家庭云转存的文件」

```bash
python3 {baseDir}/scripts/main.py search-transfer \
  --start-at "2026-08-01" --end-at "2026-08-31 23:59:59" \
  --transfer-type 6
```
